# Binarium Smart Contracts

Official smart contracts for **Binarium ($BNR)** — the on-chain mining store of value token for BNB Chain.


## Tokenomics

- **Total Supply:** 56,000,000 $BNR (fixed forever)
- **Mining Rewards:** 95% (53.2M)
- **Initial Liquidity:** 5% (2.8M)
- No presale, no team allocation, no VC tokens
